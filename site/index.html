Discord en tu terminal.

Chat, voz con cifrado de punta a punta, pantalla compartida y transmisiones, sin abrir la app de Discord. Lo manejás con el mouse o con teclas estilo vim.

probalo 
$ git clone https://github.com/gonzalonicolasr/discord-tui
$ cd discord-tui && bun install
$ bin/zcord demo

bin/zcord demo abre la interfaz con datos de prueba, sin loguearte. bin/zcord entra con tu cuenta (QR la primera vez).

qué hace

zcord/
├──
chat
servidores, canales, DMs, hilos y foros. Markdown, código, respuestas, reacciones, menciones, encuestas y embeds.
├──
voz
cifrado E2EE de Discord (DAVE) con código de privacidad, VAD o push-to-talk, volumen por persona.
├──
pantalla
compartís tu monitor con Go Live y mirás las transmisiones de los demás.
├──
imágenes
avatares, GIFs animados y emojis dibujados de verdad con el protocolo gráfico de Kitty.
└──
pegar
Ctrl-v adjunta una captura o los archivos que copiaste.

teclas

  • iescribir
  • j kmoverse
  • Ctrl-ksaltar a un canal
  • rresponder
  • eeditar el tuyo
  • ddborrar el tuyo
  • ventrar a la llamada
  • espaciopush-to-talk
  • Scompartir pantalla
  • wver una transmisión
  • ?todas las teclas
  • qsalir

requisitos

necesita
Linux con Wayland y PipeWire, Bun y una terminal con protocolo Kitty (Ghostty o Kitty).
opcional
wl-clipboard para pegar; wf-recorder o ffmpeg para compartir pantalla.
antes de usarlo

zcord entra con tu cuenta personal, no como bot. Eso va contra los Términos de Discord y la cuenta puede terminar suspendida: usalo sabiendo ese riesgo. No tiene nada que ver con Discord Inc.
